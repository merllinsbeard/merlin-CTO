# Рубрика премиальности (для оценки снимков экрана)

Используется как вопрос к `vision_analyze` для каждого ключевого экрана. Оценка по каждому критерию + конкретные слабые места, не общие слова.

## Критерии (оценка по 10)

1. **Типографика.** Не дефолтный системный шрифт; отрицательный трекинг заголовков; табличные цифры у дат/времени/таймкодов; иерархия из трёх уровней, а не только жир/размер; канцелярские форматы дат («19 авг. 2026 г.») — минус.
2. **Отступы и сетка.** Ровный вертикальный ритм; нет «пустой середины» строк (60–70% ширины без контента); выровненные колонки; единая шкала радиусов скруглений.
3. **Цвет и слои.** Есть брендовый акцент, а не только серый + семантические тинты; контраст карточка/фон; тени/слои (плоский «вайрфрейм» — минус); бейджи без «наклеечных» насыщенных рамок; различение состояний не только текстом.
4. **Плотность и контент.** Строки списков либо плотнее, либо богаче (мета, длительность, действия); одинаковые демо-данные во всех строках — пометить, но не как дефект продукта.
5. **Состояния.** Согласованы между собой: бейдж «Готово» не соседствует с ошибками блоков; оверлеи ошибок центрированы; скелетоны/постеры вместо чёрных дыр; кнопка действия в ошибке.
6. **Кликабельность и аффордансы.** Ховер-подъём/подсветка строк; видимый аффорданс перехода (не только маленький шеврон); зоны нажатия ≥44 на мобильном; второстепенные действия не сливаются с фильтрами.
7. **Человечность данных.** Технические идентификаторы (`speaker_0`) вместо человеческих лейблов — минус; машинная капитализация («Библиотека Встреч») — минус; пустые «дыры» под короткими колонками — минус.

## Вердикт снимка

```
Оценка: <n>/10 (шаблонно-анонимно → дорого)
Топ-3 быстрых фикса: <по соотношению эффект/стоимость>
Что уже хорошо: <для баланса>
```

## Антиметрики (не рекомендовать)

- Тревожные красные баннеры/модалки для обработки и ошибок распознавания.
- Автоскролл, который борется с пользователем.
- «Суп из бейджей» на каждой строке (сентимент, talk-ratio, аватары ×N) и зебра-полосы — читается как админка.
- Тёмная тема, i18n, виртуализация списков как «премиум-фиксы».

## Источники паттернов (для референс-скана)

Продуктовые кабинеты с сильным «дорогим» чтением в этой категории: Granola (markdown-нативный экспорт, минимальные списки), Otter (follow-along транскрипта), Fireflies (форматы экспорта, статусы обработки), tl;dv (подсветки таймлайна), плюс общие ориентиры: shadcn/ui theming, linear.app/method. Живая проверка каждого — обязательна в момент аудита; без неё паттерн помечается «по знаниям».
